Paste EZ Trav payload✕

In EZ Trav, the active traverse is published to localStorage.ez_current_job on every recompute. When EZ Trav and EZ Map run as separate double-clicked files, browsers may not share file:// storage — so the reliable path is to copy that JSON and paste it here.

Shape: { traverse: { points: [{calc,n,e}], closed }, job_number, client_name, … }. A bare [{P,N,E,D}] array also works.

Import PNEZD CSV✕

One point per line, comma- or space-delimited. Column order P, N, E, Z, Desc (the Carlson / EZ Trav default). Z is ignored for the search map. A header row is auto-skipped.

Desc codes PLSS/SC/1/4 tag a point to ring 3; CP/HUB → CP square; RP/WIT → witness. Everything else → ring-1 FIND/SET.
